# Respuestas

1. **¿Qué función cumple `@Component`?** Le dice a Angular que `App` es un componente y qué HTML debe mostrar.
2. **¿Para qué sirve la interfaz `Producto`?** Me dice qué datos debe tener un producto y de qué tipo son.
3. **¿Qué hace `{{ }}`?** Sirve para mostrar un dato en la página, como el nombre del producto.
4. **¿Qué diferencia existe entre `@if` y `@for`?** Con `@if` muestro algo si se cumple una condición. Con `@for` recorro una lista, como la de categorías.
5. **¿Por qué `tiendaAbierta` utiliza el tipo `boolean`?** Porque la tienda solo puede estar abierta (`true`) o cerrada (`false`).
